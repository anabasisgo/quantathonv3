# Quantathon v3: Quantum Rings runtime predictor

This branch contains a participant solution for the [public Quantum Rings challenge](https://github.com/Quantum-Rings/quantumrings-challenge-quantathonv3). The runnable v5 model is in [`quantathon-harness/model.py`](quantathon-harness/model.py); use [`solution/README.md`](solution/README.md) for instructions, validation evidence, and limitations.

The repository's 532 training-circuit filenames and 1,497-row label file match the public organizer release. The existing circuits, labels, harness scripts, and `notes/` are retained. No organizer hidden-set score or final competition submission is included.
